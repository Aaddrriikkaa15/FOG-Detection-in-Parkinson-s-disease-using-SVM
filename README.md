# FOG-Detection-in-Parkinson-s-disease-using-SVM

Developed a machine learning framework to detect Freezing of Gait (FoG) episodes in patients with Parkinson’s disease using multimodal wearable sensor data, including EEG, EMG, accelerometer, and skin conductance signals. Processed and analyzed 5.3M+ time-series samples, implemented preprocessing and sliding-window segmentation, and trained a Support Vector Machine (SVM) classifier achieving ~70% accuracy. Evaluated performance using F1-score, MCC, ROC curves, and confusion matrix analysis. The research was published in IJIRT.
